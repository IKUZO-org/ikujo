## 0. 방식
**범인별 진실표 4장 + 공통 뼈대.** 범인 후보 4명(핵심 인물)마다 "그날 밤 실제로 있었던 일"을 한 장씩 둔다. 판마다 그중 한 장이 진짜가 되고, 나머지 인물은 범인이 아니어도 숨길 이유가 있다(§28.8). 모든 단서는 어느 진실표에서 나왔는지(`pointsTo`)를 갖고, 범인이 아닐 때 의심받는 단서는 레드 헤링으로 진짜 이유를 갖는다.

- 고른 이유: 판마다 범인이 바뀌어도 단서끼리 모순이 없는지 표로 검사할 수 있고, 지금 JSON 구조(`culprits`, `pointsTo`, `redHerrings`)에 그대로 맞는다
- 안 고른 것: 진실 하나에 범인 이름만 바꾸기(동기, 실수가 어색해지고 다시 할 때 같은 이야기), 6명 모두의 그날 밤(분량 4~5배)

## 1. 인물 (화면 표기)
화면에는 **직업**을 쓰고, 방송 속 이미지는 소개 글로 보여 준다. "악역", "호감"은 기획용 별명이라 화면에 쓰지 않는다 (악역 비밀 "PD가 시킨 대본이었다"가 처음부터 드러나기 때문). 코드 ID는 그대로 둔다.

| ID | 화면 표기 | 소개 글 (방송 속 이미지) |
| --- | --- | --- |
| (피해자, NPC) | 메인 PD **강도윤** | 「LAST ONE」을 만든 사람. 내일 결승 생방송에서 조작을 폭로하려 했다 |
| fav | 출연자 · 유치원 교사 **윤하늘** | 시청자 투표 1위. 늘 웃고 남을 챙겨 '국민 호감'으로 불린다 |
| villain | 출연자 · 헬스 트레이너 **차민혁** | 별명 '독설 트레이너'. 매회 싸움을 걸어 가장 욕을 많이 먹는다 |
| athlete | 출연자 · 전직 유도 국가대표 **김태오** | 은퇴 뒤 처음 나온 방송. 상금이 꼭 필요하다고 말한다 |
| writer | 막내 작가 **이소라** | 제작진 중 유일하게 섬에 남았다 |
| influencer | 출연자 · 뷰티 인플루언서 **제나** (본명 정예나) | 팔로워 300만. 방송보다 자기 SNS에 더 열심이다 |
| medic | 의료진 · 응급의학과 의사 **박정우** | 촬영 내내 섬에 머무는 의사 |
| (과거, NPC) | 3주 차 탈락자 **한서진** | 절벽 미션 사고의 피해자 |

비밀과 둘만 아는 비밀(§28.3, §28.5)은 뜻은 그대로 두고 별명을 이름으로 바꾼다. 예: "악역은 PD가 시킨 대본이었다" → "방송 속 독설은 강도윤 PD가 시킨 대본이었다".

## 4. 유령 특징 (OQ-013 닫기)
4~5명 판에서도 특징이 그 판의 2명 이상에게 맞도록, 이야기에 이유를 붙여 해당자를 늘린다.

| 특징 | 지금 | 바꾼 뒤 | 붙인 이유 |
| --- | --- | --- | --- |
| t-citrus 시트러스 향수 | fav, influencer | fav, **writer**, influencer | 윤하늘이 이소라에게 같은 향수를 선물함 (둘만 아는 사이). 제나는 뷰티 인플루언서라 늘 뿌림 |
| t-black-cap 검은 볼캡 | villain, athlete, medic | 그대로 | 4명 판에도 2명 |
| t-limp 다리 저는 걸음 | athlete, medic | athlete, **villain**, medic | 차민혁이 어제 미션에서 발목을 접질림 (c-r1-02) |
| t-radio 무전기 소리 | writer, medic | writer, **villain**, medic | 차민혁이 PD와 대본을 맞추려고 무전기를 받아 둠 (c-r1-08) |

4명 판(fav, villain, athlete, writer)에서 각 특징의 해당자: 시트러스 2, 볼캡 2, 걸음 2, 무전기 2.

### 희생자 고르기 규칙 고침 (BR-004 보강)
희생자가 특징 해당자면, 유령은 자기가 아닌 걸 아니까 사실상 1명으로 좁혀진다. 그래서 희생자는 **범인이 아니면서 특징에 해당하지 않는 핵심 인물**을 먼저 고르고, 그런 사람이 없을 때만 해당자에서 고른다.
- 4명 판 예: 범인 윤하늘(시트러스: 윤하늘, 이소라) → 희생자는 차민혁, 김태오 중에서
- 고칠 곳: `src/server/assign.ts` 희생자 고르기와 검사, `src/server/assign-ai.ts` 프롬프트, 테스트

## 6. 해설 엔딩 (`reveal.endings`)
지금은 "검거 성공", "방송 중단" 한 줄이다. 이름을 끼우는 기능은 없으므로 이름 없이 쓴다.

- **caught**: 범인이 잡혔다. 새벽, 쓰러졌던 사람이 깨어나 정전 때 복도에서 스친 사람을 증언한다. 결승 생방송은 취소되고, 강도윤 PD가 남긴 원본은 한서진에게 전해진다
- **aired_off**: 범인을 잡지 못한 채 아침이 왔다. 결승 생방송은 예정대로 나가고, 사라진 원본 하드는 끝내 나오지 않았다. 3주 차의 진실은 다시 묻혔다
