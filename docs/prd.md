## 1. 한 줄 요약
**서비스 이름: LAST ONE** (D-017). 첫 시나리오 속 예능 이름과 같다.

4~6명이 한자리에 모여 각자 폰으로 방 코드에 들어가면(가입 없이도), AI 진행자가 매 판 범인과 희생자, 단서를 새로 정해 나눠 주고, 라운드마다 단서를 풀고, 투표 뒤 진상을 해설해 주는 오프라인 파티 추리 게임.

## 2. 제품 비전
폰은 **"비밀 카드"와 "진행자"** 로만 쓰고, 나머지 시간은 얼굴을 보고 대화한다. 머더 미스터리 키트처럼 한 번 하면 끝나는 게 아니라, 같은 이야기라도 **매 판 범인이 달라져서 같은 비밀도 다르게 읽히고, 또 할 수 있는** 게임. (비밀은 인물마다 기본 1개, D-016)

## 3. 문제
| ID | 문제 | 근거 |
| --- | --- | --- |
| P-1 | 머더 미스터리 키트는 비싸고 한 번 하면 끝이다 | 조 기획 글 |
| P-2 | 모임에서 다같이 할 거리가 마땅치 않다 | 조 기획 글 (대상: 모임에서 할 거리를 찾는 사람) |
| P-3 | 사람이 진행자를 맡으면 그 사람은 게임을 못 즐기고, 비밀을 나눠 주는 준비가 번거롭다 | 제안 (회의에서 확인) |

## 4. 대상 사용자
| ID | 사용자 | 상황 | 상태 |
| --- | --- | --- | --- |
| U-1 | 모임에서 할 거리를 찾는 친구 무리 4~6명 | 같은 공간(집, 카페, MT)에 모여 있다 | 확정 |
| U-2 | 방장(호스트) | 방을 만들고 시작을 누른다. 같이 플레이한다 | 확정 |
| U-3 | 집에서 온라인으로 하고 싶은 사람 (마피아42 사용자) | 떨어져 있다 | **나중** (D-001) |

## 5. 사용자가 원하는 것 (Jobs)
- 모였을 때 **준비 없이** 바로 30~40분 놀 거리를 시작하고 싶다
- 진행자 없이 **모두가 플레이어**로 참여하고 싶다
- 범인만 찾는 게 아니라 **내 비밀과 거짓말할 이유**가 있어 대화가 재밌어지길 원한다
- 끝나면 **"그래서 진짜는 뭐였는데?"** 를 깔끔하게 알고 싶다

## 6. 가치 제안
| 무엇이 | 왜 AI인가 |
| --- | --- |
| 매 판 다른 범인 | AI가 고정 뼈대 안에서 범인, 희생자(유령), 단서 배분을 매번 다르게 정한다. 비밀은 인물마다 기본 1개지만 범인이 바뀌면 누가 무엇을 숨기는지가 달라진다 |
| 진행자 없음 | AI 진행자가 설명, 라운드 진행, 이벤트, 타이머를 맡는다 |
| 우리 판 맞춤 해설 | 이번 판의 범인, 투표 결과, 누가 무엇을 숨겼는지로 해설을 만든다 |

## 8. 범위 요약
- **MVP (이번)**: 오프라인 같은 공간, 4~6명, 방 코드 입장, 시나리오 1편 「생방송 중 사망」, AI 진행(배정, 진행, 투표 판정, 해설), 웹앱
- **다음**: 온라인 원격 플레이, 대화 듣고 판정(음성 인식), 시나리오 추가, QR 입장
- 자세히는 §9, §27

## 9. 범위
### MVP 안
1. 회원 (로그인, 로그아웃, 회원 탈퇴). 로그인은 선택이고 손님 입장 가능 (D-009, D-010)
2. 온보딩 (건너뛰기 가능)
3. 방 만들기 → 방 코드 → 코드 입력으로 입장 → 대기실 → 시작
4. AI 진행자: 이야기 설명, 범인과 희생자와 비밀 배정, 라운드 진행, 이벤트, 투표 집계와 판정, 해설
5. 공용 화면과 개인 화면 (모든 폰에 둘 다)
6. 라운드 3개 + 투표 + 해설, 유령 플레이어
7. 가상 폰 UI 연출 (가상 메신저, 속보, 전화 수신 흉내, TTS 음성)
8. 소리, 이미지, 영상 연출
9. 완료한 게임에 체크 표시
10. 설정 (상단 네비)

## 12. 화면 흐름
```
온보딩(건너뛰기) → 홈(입장방) — 로그인은 선택 (홈 또는 설정에서)
  ├─ 방 만들기 → 방 코드 표시 → 대기실(방장: 시작 버튼)
  └─ 코드 입력 → (로그인 안 했으면) 닉네임 → 대기실
대기실 → 시나리오 시작(이야기 설명) → 인물 카드 → R1 → R2 → R3 → 투표 → 해설 → 홈(완료 체크)
상단 네비: 설정 (어느 화면에서나)
```

### 12.1 화면별 상태
| 화면 | 정상 | 빈/대기 | 오류 |
| --- | --- | --- | --- |
| 코드 입력 | 입장 → 대기실 | — | 없는 코드, 꽉 찬 방(6명), 이미 시작한 방 |
| 대기실 | 들어온 사람 목록, 방장만 시작 | 4명 미만이면 시작 버튼 꺼짐 + "4명부터 시작해요" | 방장이 나감 → 다음 사람이 방장 (BR-012) |
| 배정 중 | — | "진행자가 사건을 준비하고 있어요" | AI 실패 → 다시 시도 (FR-020) |
| 라운드 | 단서, 타이머, 준비 완료 현황 | 새 단서 없음 | 연결 끊김 → 다시 연결 (NFR-002) |
| 투표 | 선택 → 완료 | 완료 인원만 표시 | 시간 초과 → 미투표 처리 (BR-007), 동점 → 재투표 (BR-013) |

## 13. 정보 구조 — 공용 화면과 개인 화면
모든 폰이 공용 화면과 개인 화면을 다 가진다. 같은 공간이라 공용 화면은 "모두의 폰에 같은 내용"이다. (D-004)

### 상단 고정 (항상)
- 사건 제목, 지금 단계(예: "라운드 2 · 토론 중"), 등장인물 목록 보기 버튼, 설정

### 공용 화면
| 단계 | 보이는 것 |
| --- | --- |
| 사건 소개 | 사건 제목, 장소, 피해자, 발견 상황 요약, 등장인물 카드(이름, 관계, 한 줄 소개) |
| 비밀 확인 | "각자 폰으로 비밀을 확인하세요", 확인 현황 (예: 4/5명) |
| 라운드 | 라운드 번호(1/3), 이번 라운드 공개 단서, 지금까지 공개 단서 목록, 토론 타이머, 준비 완료 현황, 이벤트 알림 |
| 투표 | 투표 안내, 완료 현황(예: 3/5명), 남은 시간 |

### 개인 화면
| 단계 | 보이는 것 |
| --- | --- |
| 비밀 확인 | "당신은 ○○입니다", 내 인물 소개, 내 비밀, 정전 때 알리바이, (범인만) "당신이 범인입니다. 생방송 전까지 들키지 마세요." 확인까지 남은 시간 |
| 라운드 | 나에게만 온 단서 |
| 유령 | 범인의 흐릿한 특징, 속삭임 보내기, 출몰 1회 |

### 공용 화면에 절대 넣지 않는 것 (BR-001)
- 범인 정보, 진실 타임라인 (해설 전까지)
- 개인 비밀, 개인 단서, 각자의 목표
- 투표 중 개별 선택 (완료 인원 수만)

## 14. 기능 요구사항

### 회원
**FR-001 로그인, 로그아웃, 회원 탈퇴** `확정` (방식은 `미정` OQ-002)
- 로그인은 **선택**이다. 로그인하면 완료 기록(FR-090)이 계정에 남는다 (D-010)
- 탈퇴하면 계정과 완료 기록을 지운다

**FR-003 손님 입장** `확정` (D-009)
- 로그인 없이 방 코드 + 닉네임(1~10자)으로 입장한다
- 손님은 한 판 동안만 쓰는 손님 세션을 받는다. 같은 폰으로 다시 열면 같은 자리로 돌아온다 (NFR-002)
- 손님도 방장이 될 수 있다 `제안`
- 같은 방에서 닉네임이 겹치면 뒤에 숫자를 붙인다 `제안`

**FR-002 온보딩** `확정`
- 첫 실행 때 게임 방법을 몇 장으로 보여 준다. 건너뛰기 가능. 설정에서 다시 볼 수 있다 `제안`

### 방
**FR-010 방 만들기** `확정`
- 방장이 만들면 방 코드가 생긴다. QR은 MVP에서 빼고 코드만 (D-003)
- 방 코드: 숫자 4~6자리 `제안`, 진행 중인 방끼리 겹치지 않는다

**FR-011 코드 입장** `확정`
- 코드를 넣으면 대기실로. 오류: 없는 코드 / 꽉 참(6명) / 이미 시작함 → 각각 한 줄 안내

**FR-012 대기실** `확정`
- 들어온 사람 목록, 인원 표시(n/6). 방장에게만 시작 버튼

**FR-013 시작** `확정`
- 4~6명일 때만 시작 가능. 시작하면 새로 들어올 수 없다 `제안`

### AI 배정
**FR-020 범인, 희생자, 비밀 배정** `확정`
- 인원에 맞춰 인물을 정한다: 핵심 4명은 항상, 추가 2명(인플루언서, 의료 담당)은 5~6명일 때만 (BR-002)
- 범인 1명: 핵심 4명 중 하나 (BR-003)
- 희생자(유령) 1명: 범인을 뺀 핵심 인물 중 무작위 (BR-004)
- 각 인물의 비밀, 알리바이, 라운드별 개인 단서를 정한다
- 고정 뼈대(시간, 장소, 수법)는 바꾸지 않는다 (BR-005)
- 배정 결과는 서버에만 두고 각 플레이어에게 자기 것만 보낸다 (NFR-004)
- **CAG 방식** `확정` (D-011): 시나리오 전체(뼈대, 인물, 비밀, 단서 풀, 특징, 해설 틀)를 고정 맥락(프롬프트 캐시)으로 넣고, AI는 그 안의 ID만 골라 돌려준다. 새 사실을 지어내지 않는다
- 서버가 결과를 규칙(BR-002~006)으로 검사한다. 어긋나면 다시 고르게 하고, 2번 실패하면 규칙만으로 무작위 배정 `제안`
- 수용 기준 → AC-020

**FR-021 AI 진행자 설명** `확정`
- 시작하면 진행자가 이야기 설정과 규칙을 설명한다 (글 + TTS `제안`)

### 인물 카드
**FR-030 역할과 비밀 확인** `확정`
- 비밀은 인물마다 기본 1개 (D-016). 시나리오 데이터는 후보 목록 구조로 두어 나중에 늘릴 수 있게 한다
- 각자 개인 화면에서 확인. 공용 화면에 확인 현황(n/N). 모두 확인하거나 시간이 끝나면 R1로 `제안`

### 라운드
**FR-040 라운드 진행** `확정`
- R1, R2, R3 순서. 라운드마다 장소와 시점이 바뀌고(§11) 새 단서가 열린다

**FR-041 단서 공개** `확정`
- 공용 단서는 모두에게, 개인 단서는 그 사람에게만. 지금까지 공개 단서 목록을 언제든 본다

**FR-042 토론 타이머** `확정`
- 라운드별 시간(R1 8분, R2 10분, R3 8분). 연장 가능 여부 `미정` (OQ-007)

**FR-043 준비 완료** `확정`
- 각자 "준비 완료"를 누를 수 있고 현황을 공용 화면에 보인다. 모두 준비되면 타이머 전에 다음으로 넘어갈지 `미정` (OQ-007)

**FR-044 라운드 이벤트** `확정`
- 예: 가상 단톡방 메시지, 긴급 속보, 전화 수신 연출 (FR-080)

### 유령
**FR-050 희생** `확정`
- R2 시작과 동시에 FR-020에서 정한 희생자가 유령이 된다
- 희생자 폰: 녹화 화면이 끊기며 유령 모드, 범인의 흐릿한 특징이 보인다
- 나머지 폰: 긴급 속보 "○○, 해변에서 쓰러진 채 발견"

**FR-051 범인 특징 보기** `확정`
- 범인별로 정한 특징 하나(§28.6). 그 특징은 그 판의 2~3명에게 해당한다 (BR-006)

**FR-052 속삭임** `확정`
- 한 명에게 몰래 메시지. 횟수 `미정` (원문 "가능"만 있음, OQ-005)

**FR-053 출몰** `확정`
- 모두에게 1회, 시기 자유. 연출: 모든 폰에 "생방송 연결" 화면 + 유령의 말
- 유령은 투표하지 않는다

### 투표와 판정
**FR-060 투표** `확정`
- 살아 있는 플레이어만, 한 명을 지목. 완료 인원만 공용 화면에 (BR-001)
- 시간 3분
- **동점이면 재투표** `확정` (D-013): 최다 득표 동점자만 후보로 1분 재투표 `제안`. 재투표도 동점이면 "방송 중단"(범인 승리) `제안`

**FR-061 판정** `확정`
- 최다 득표자가 범인이면 "검거 성공", 아니면 "방송 중단" 등 엔딩 분기 `제안`

### 해설
**FR-070 AI 해설** `확정`
- 범인 공개, 투표 결과(누가 누구를 지목했는지), 진실 타임라인, 핵심 단서, 범인의 실수, 유령이 본 장면의 의미, 레드 헤링 설명, 과거 사고의 진실, 추리 평가(가장 정확히 추리한 사람), 엔딩
- 우리 판 맞춤 해설(이번 판에 누가 무엇을 숨겼는지, 누가 누구를 지목했는지) `확정` (D-014). CAG로 이번 판 배정과 투표를 넣어 만든다
- 다시 하기 버튼 → 같은 사람들로 새 판 `제안`

**FR-071 추리 평가 기준** `확정` (D-015)
- 대화를 듣지 않는 MVP에서는 투표만으로 평가한다: **범인을 지목한 사람**이 "정확히 추리한 사람"
- 재투표가 있었으면 마지막 투표 기준 `제안`. 아무도 못 맞히면 "이번엔 범인이 이겼어요" 

### 연출
**FR-080 가상 폰 UI와 TTS** `확정`
- 문자, 단톡방, 사진첩, 음성 메시지, 잠긴 폰, 전화 수신을 흉내 낸 화면
- 실제 서비스(카카오톡, iOS)를 그대로 따라 하지 않는다. 게임 속 가상 메신저와 폰 UI (BR-008)
- 진짜 전화, 문자를 보내지 않는다

**FR-081 소리, 이미지, 영상** `확정`
- 소리: 종소리, 파도, 타이핑, BGM, 진동
- 이미지: 배경, 개인 화면 이미지, 이펙트
- 영상: 짤, 오프닝, 마무리, CCTV 장면
- 소리 끄기 설정 `제안`

### 기타
**FR-090 완료 체크** `확정`
- 끝낸 게임(시나리오)에 체크 표시. 로그인한 사람만 저장 (D-010). 손님에게는 "로그인하면 기록이 남아요" 안내 `제안`

**FR-091 설정** `확정`
- 상단 네비에서. 소리, 진동, 온보딩 다시 보기, 로그아웃, 탈퇴 `제안`

## 22. 수용 기준
- **AC-011** 없는 코드를 넣으면 "없는 방이에요"가 뜨고 대기실로 가지 않는다
- **AC-012** 대기실에 3명이면 방장의 시작 버튼이 꺼져 있다
- **AC-020-1** 4명으로 시작하면 인물은 핵심 4명만, 범인은 그중 하나다
- **AC-020-2** 6명일 때 희생자는 범인이 아닌 핵심 인물이다 (추가 인물은 희생자가 아니다)
- **AC-020-3** 100판을 배정해도 사건 시각(21:30, 21:50, 22:00, 22:12)과 수법은 같다
- **AC-030** 범인 폰에만 "당신이 범인입니다"가 보이고, 공용 화면 어디에도 범인 이름이 없다
- **AC-050** R2가 시작되면 희생자 폰은 유령 모드, 나머지는 속보 화면이 2초 안에 뜬다
- **AC-051** 유령이 본 특징은 그 판에 있는 인물 2명 이상에게 해당한다
- **AC-053** 유령은 출몰을 두 번 쓸 수 없고, 투표 화면에서 선택할 수 없다
- **AC-060** 투표 중 공용 화면에는 "3/5명 완료"만 있고 누가 누구를 골랐는지 없다
- **AC-070** 해설에 범인, 투표 결과, 진실 타임라인, 레드 헤링 설명이 모두 있다
- **AC-NFR-002** R2 중 폰을 잠갔다 열면 R2 화면과 내 단서가 그대로 있다
- **AC-003** 로그인하지 않은 사람이 코드와 닉네임만으로 대기실에 들어간다
- **AC-020-4** AI가 시나리오에 없는 인물이나 단서 ID를 돌려주면 서버가 거절하고 다시 고른다
- **AC-060-2** 2명이 2표씩 동점이면 그 2명만 후보로 재투표 화면이 뜬다
- **AC-071** 해설의 "정확히 추리한 사람"은 범인을 지목한 사람과 같다
- **AC-BR-011** 범인이 아닌 1명이 나가도 다음 라운드로 넘어가고, 투표 완료 인원에서 빠진다

## 28. 부록 — 시나리오 「생방송 중 사망」 (정연)

### 28.1 설정
상금 10억이 걸린 무인도 서바이벌 예능 「LAST ONE」. 내일은 결승 생방송. 폭풍으로 제작진 배가 섬을 떠난 밤, 메인 PD가 편집실에서 쓰러진 채 발견된다. 그는 내일 생방송에서 "이 쇼는 처음부터 조작이었다"고 폭로할 예정이었다.

- 모인 이유: 결승 생방송 전날 밤, 결승 진출자 4명과 섬에 남은 스태프 2명이 숙소에 있다
- 밝혀질 예정: PD가 "쇼 조작"과 "3주 차 사고의 진실"을 폭로하려 했다
- 고립: 배는 철수, 통신은 위성 전화 하나인데 정전으로 먹통
- 사건: 정전 10분 사이 PD가 편집실에서 습격당하고 원본 하드디스크가 사라진다

### 28.2 고정 뼈대 (범인이 누구든 같다)
| 시각 | 일 |
| --- | --- |
| 21:30 | PD가 제작진 단톡방에 "내일 생방송에서 전부 말할 거야. 원본은 편집실에 있다." |
| 21:50 | 누군가 발전기실 차단기를 내린다 |
| 22:00 | 섬 전체 정전 (10분) |
| 22:00~22:10 | 범인이 편집실에서 PD를 결승 트로피로 내리치고 원본 하드디스크를 가져간다 |
| 22:12 | 비상 전원, 쓰러진 PD 발견 |

### 28.3 인물
| 구분 | 인물 | 한 줄 소개 | 비밀 (기본 1개, D-016) |
| --- | --- | --- | --- |
| 핵심 | 국민 호감 1위 | 착한 이미지로 인기 1위 | 제작진에게 미리 미션 내용을 받았다 |
| 핵심 | 악역 담당 | 방송에서 욕먹는 캐릭터 | 악역은 PD가 시킨 대본이었다 |
| 핵심 | 전직 운동선수 | 상금이 꼭 필요한 사람 | 큰 빚이 있고 사채업자에게 쫓긴다 |
| 핵심 | 막내 작가 | 제작진이지만 섬에 남은 사람 | 원본 영상 백업을 몰래 갖고 있다 |
| 추가 | 인플루언서 | 팔로워 300만, 방송보다 SNS | 섬에서 몰래 라이브를 켰었다 |
| 추가 | 의료 담당 | 출연자 건강 체크 스태프 | 탈락자 "사고" 기록을 고쳤다 |

### 28.4 과거 사건: 3주 차 "절벽 미션 사고"
- 공식: 3주 차 탈락자 '한서진'이 개인 사정으로 자진 하차
- 진실(고정): 절벽 로프 미션에서 서진의 안전 로프가 낡은 것으로 바꿔치기되어 추락, 크게 다침. 제작진이 시청률을 위해 덮음
- 인물별 고리: 호감(미션을 미리 들음) · 악역(대본대로 도발) · 선수(미션 파트너, 로프 마지막 점검) · 작가(촬영 담당, 원본 백업) · 인플(몰래 라이브에 사고 직후 소리) · 의료(기록을 "단순 염좌"로 고침)

### 28.5 둘만 아는 비밀과 긴장
| 관계 | 비밀 | 긴장 |
| --- | --- | --- |
| 호감 ↔ 작가 | 작가가 미션 내용을 흘렸다 | 들키면 둘 다 끝 |
| 악역 ↔ 작가 | 악역 대본을 작가가 썼다 | 악역은 "나도 피해자"라고 말하고 싶다 |
| 선수 ↔ 악역 | 악역이 선수의 빚을 안다 | 악역이 협박해 왔다 |
| 선수 ↔ 의료 | 의료가 몰래 진통제를 줬다 | 선수는 부상을 숨기고 출전 중 |
| 호감 ↔ 인플 | 인플이 호감의 "착한 척 안 하는" 영상을 갖고 있다 | 인플은 팔로워를 노린다 |
| 인플 ↔ 의료 | 둘 다 사고 당일 밤 현장 근처에 있었다 | 말하지 않기로 약속 |

### 28.11 조원 의견 (원문 요약)
- 상경: 온라인 소통은 목적이 만남이었다. 한자리에 모인 사람들 사이에서 폰을 "비밀 카드"와 "진행자"로만, 화면을 최대한 덜 보게
- 현경: 오프라인 전용. 폰에는 캐릭터 정보, 특징, 스토리만. 추리는 대화로, 지목은 투표로
- 지영: 오프라인에서 폰이 도구가 되는 느낌
- 정연: 오프라인, 모임에서 쓰는 도구 정도의 범위
- 시나리오 평: 장치 방식과 유령(정연), 개인 목표와 인물 구조(지영), 돈에 관한 소재(현경)
