## 0. 먼저 정할 규칙 `제안`

같은 방에 폰 4~6대가 같이 울리므로 웹 게임과 다르게 정한다.

1. **공용 소리는 방장 폰 하나에서만.** BGM, 앰비언스, 내레이션, 라운드 종은 방장 폰만 낸다. 여러 폰이 같이 내면 어긋나서 메아리처럼 들린다
2. **개인 소리는 내 폰에서만, 짧게.** 새 단서, 속삭임, 버튼 반응. 0.5초 안팎
3. **예외: 유령 출몰(GH-04)은 모든 폰이 같이.** 방 전체에서 지직거리는 게 연출이다
4. **비밀이 소리로 새지 않게 (BR-001).** 범인과 범인 아닌 사람의 인물 카드 소리는 똑같다. 소리 길이, 횟수로도 구별되면 안 된다
5. **소리 없이도 전부 된다 (NFR-007).** 모든 큐에 "소리 끄면" 칸을 둔다. 진동은 iOS Safari에서 안 되므로(Vibration API 없음) 진동만으로 알리지 않는다
6. **첫 탭에서 소리 열기.** 모바일 브라우저는 사용자가 누르기 전에 소리를 못 낸다. 대기실 입장이나 "시작" 누를 때 소리를 열어 둔다 (개발 메모)

## 2. 목소리 (TTS) 대사 — OQ-011

**정함 (2026-11-26): TTS를 쓰지 않는다.** 아래 대사는 모두 자막과 글로 낸다. 영상도 음성을 만들지 않으므로(video/PLAN.md VQ-4) 목소리 없는 쪽으로 맞춘다. PRD OQ-011을 닫을 차례. 아래 표와 `제안`은 정하기 전 기록으로 남긴다.

| ID | 누구 목소리 | 대사 근거 | 판마다 바뀜? |
| --- | --- | --- | --- |
| OP-03 | 진행자 | 방송 예고, 설정과 규칙 (FR-021, §28.1) | 아니오 |
| OP-08 | 진행자 | PD 발견 내레이션 (22:12) | 아니오 |
| R2-03 | PD | 음성 메모 | 아니오 (내용은 시나리오에서 정해야 함) |
| R2-04 | 전화 상대 | 전화 수신 대사 | 아니오 (내용은 시나리오에서 정해야 함) |
| (없음) | 진행자 | 해설 1~7 | 범인 4명에 따라 4벌. 8번 맞춤 해설은 판마다 달라 글로만 |

`제안`: 대사가 고정이라 **생성한 목소리를 파일로 미리 만들어 둔다.** 판마다 생성하지 않으니 비용과 기다림이 없고, 사람 녹음보다 빨리 고칠 수 있다. 해설 1~7은 처음엔 글로만, 여유가 되면 범인별 4벌을 만든다. 정하면 PRD OQ-011을 닫는다.

## 3. 파일 규칙 `제안`

- 자리: `public/sounds/<ID 소문자>.mp3` (예: `public/sounds/rd-01.mp3`). 개발은 이 ID로 자리를 만들고, 파일이 없으면 조용히 건너뛴다 (PRD §24)
- 형식: mp3 (iOS Safari, 안드로이드 크롬 모두 재생). 효과음 100KB 안팎, BGM과 앰비언스 루프는 1MB 이하
- 크기 맞추기: 모든 파일의 소리 크기를 비슷하게 맞추고, 앰비언스는 대사보다 확실히 작게
- 목록 관리: 파일을 넣을 때 아래 4번 표에 출처와 라이선스를 같이 적는다

## 4. 찾을 곳과 라이선스

레포가 공개라서 **상업적으로 써도 되고, 재배포 조건을 지킬 수 있는 소리만** 쓴다. 받을 때 그 페이지의 라이선스를 직접 확인한다.

| 어디서 | 쓸 만한 것 | 확인할 것 |
| --- | --- | --- |
| Pixabay 효과음, 음악 | 효과음, BGM 대부분 | Pixabay 라이선스 (출처 표시 없이 사용 가능하다고 안내됨. 받을 때 다시 확인) |
| Freesound | 앰비언스, 특이한 효과음 | 소리마다 다름. **CC0만** 고르기 (CC BY는 출처 표시 필요, NC는 쓰지 않음) |
| 직접 녹음 | 종이 넘김, 무전기, 숨소리 | 녹음한 사람 이름 기록 |
| 생성 TTS | 진행자, PD 대사 | 쓰는 서비스의 상업 이용, 재배포 조건 |

하지 않을 것: 카카오톡, 아이폰 같은 실제 서비스의 알림음과 벨소리를 따라 하거나 가져오기 (BR-008), 방송사 실제 징글, 유튜브 오디오 보관함 음원(유튜브 밖 사용 조건 따로 확인 필요)

모두 Freesound **CC0** (출처 표시 의무 없음, 상업 이용과 재배포 가능). 받은 것은 Freesound 미리듣기 mp3이고, 크기를 맞췄다(효과음 -16 LUFS 128kbps, BGM -22 LUFS 80kbps). 원본 wav가 필요하면 같은 페이지에서 받는다.
