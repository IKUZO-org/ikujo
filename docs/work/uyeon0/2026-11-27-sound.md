## 할 일
소리 재생 바탕(`playSound`, BGM/앰비언스 한 겹)을 만들고, 단계가 바뀔 때 방장 폰에서 나는 공용 소리를 붙인다.

## 한 일
- `src/lib/sound.ts` 소리 재생 바탕: Web Audio 로 `public/sounds/<id>.mp3` 를 튼다. 파일이 없거나 실패하면 조용히 건너뜀
  - 첫 탭에서 소리를 연다(규칙 6). iOS Safari 도 열리게 pointerdown, touchend, click 을 같이 듣고 열리면 뗀다
  - `playSound(id, { isHost, loop })`: 효과음. 누가 내는지는 `SOUND_TARGET` 표를 따른다 (host 소리는 방장 폰만)
  - `setLayer(id, isHost)`: BGM/앰비언스는 한 번에 하나, 바뀔 때 줄이고 키운다. 소리가 열리기 전에 정한 것은 첫 탭 뒤에 튼다(새로 고침, 재접속)
  - 반복 BGM 파일 끝의 무음 때문에 반복 사이에 긴 텀이 있어, 마지막으로 약 -45dB 를 넘는 지점 + 0.05초를 반복 끝으로 둔다. 효과음은 그대로
- `src/lib/settings.ts`: 설정을 바꾸면 이벤트를 내서, 소리를 끄는 순간 BGM 과 효과음을 멈춘다(FR-091)
- `src/lib/sound-cues.ts` 맨 위 설정 표만 고치면 소리 순서, 시간, 크기가 바뀐다. 아래 함수(`pickLayer`, `phaseCues`, `shouldPlay`, `volumeFor`, `loopEndSeconds`)는 표를 읽기만 한다
  - `SOUND_IDS`/`SoundId`: `public/sounds` 의 소리 전부 (develop 의 P2 소리 cl-01, gh-02, lb-01, op-01, rv-04, vt-02 포함)
  - `PHASE_LAYER`: 단계 → BGM/앰비언스 (OP-02, R1-01, R2-02, R3-02, VT-01, RV-03)
  - `ROUND_TAIL_LAYER`, `BG_TAIL_MS` `제안`: 라운드마다 장소 앰비언스로 시작하고 끝나기 3분 전부터 BG 로 바꿈 (r1, r3 BG-01, r2 BG-02). 한 번에 한 겹만 깔리므로 장소를 먼저 알리고 마감 쪽으로 긴장을 올리려는 것
  - `TRANSITION_CUES`: 전환마다 효과음과 시각. 겹치지 않게 차례로 냄 (예: R1→R2 는 RD-05 0초, RD-01 0.8초, R2-01 2초). 표에 없는 전환은 소리 없음
  - `LAST_SECONDS_MS`(RD-04), `FADE_S`
  - `SOUND_VOLUME`: 모든 소리의 크기를 `EFFECT_VOLUME`(1) 또는 `LAYER_VOLUME`(0.5) 로 적음. R3-02 는 들어 보고 0.25
  - `SOUND_TARGET`: 소리마다 누가 내는지 host(방장 폰만, 규칙 1), self(그 폰만, 규칙 2), all(모든 폰, 규칙 3, GH-04). sound.md §1 "어느 폰" 칸을 따름
  - 표는 `SoundId`, `Phase`, `${Phase}>${Phase}` 타입이라 id 오타나 빠진 소리는 타입 오류
- `src/lib/use-room-sound.ts` + `room-view.tsx`: 단계에 맞는 소리 (누가 낼지는 `SOUND_TARGET`)
  - 방장이 바뀌면 새 방장 폰이 지금 단계 BGM 을 튼다(BR-012)
  - 전환 효과음은 전환을 직접 본 폰만 (새로 고침 뒤 처음 읽은 단계에는 내지 않음). 단계가 또 바뀌면 아직 안 낸 소리는 취소
  - RD-04 는 라운드에서 30초를 넘어가는 순간부터 단계가 끝날 때까지 반복
  - OP-02 는 intro, secret 동안. V-01 재생이 아직 없어 오프닝 진입 때 바로 틀고, `OPENING_VIDEO_DONE` 이 V-01 끝남 신호를 받을 자리
- `tests/sound-cues.test.ts`: 판정 경계(영상 전 오프닝, 라운드 끝 3분 양쪽), host 소리는 방장 폰만, 반복 끝 계산 테스트
