## 프롬프트 요약
1. V-03 로프 묶는 컷 다음에 V-02 드론 컷 1번을 넣어 달라고 함 → 드론 5초를 넣은 12.8초 버전
2. 드론 컷이 조금 길어서 3초만 쓰라고 함 → 앞 3초만 남긴 10.8초 버전
3. 그림자가 다가와 쪼그려 앉은 다음 손 클로즈업으로 갈 수 없는지, V-09를 가져다 쓰라고 함 → V-09에서 쪼그려 앉는 건 형체 자체라 머리와 몸이 보여서 R-01, R-02와 부딪힌다고 알리고 방법 3개 제안
4. 그림자만 새로 만들기를 고름 → 시작 프레임(V-09 50번째 프레임)과 끝 프레임 그림(1크레딧)을 만들어 보여 줌 → "아니다, 하지 마"라고 해서 멈춤 (영상 생성 안 함, 이 PR에 들어가지 않음)
5. 참고 이미지처럼 배터리와 가운데 십자로 카메라 원본임을 알게 하고, 한 장면만 먼저 보여 달라고 함 → 정지 시안 (REC, 남은 시간 글자는 넣지 않음)
6. V-03에서 로프 다시 묶는 것을 안 보여 주기로 했었는지 물음 → VQ-22대로 손이 로프를 바꾸는 클로즈업은 보여 주고, 형체와 끊어지는 장면만 안 보여 준다고 안내
7. V-03 전체에 배터리와 십자를 적용하라고 함 → 이 영상
8. 녹화 표시는 V-09에는 없고 V-03에만 있다고 정함 → 메모리에 적고 V-09는 결과해석 세션에 전달 (그쪽 #102에서 처리)
9. V-03 최종 영상과 바뀐 점을 먼저 보여 달라고 함 → 지금 레포 v-03과 비교 그림
10. 이슈를 만들고 올리라고 함 → 이슈 #104, 이 PR
