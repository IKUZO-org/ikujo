## 프롬프트 요약
1. V-02 C-01 하단 「CLIFF ROPE」 자막을 없애고, 편집본임을 보여 줄 표현을 만들기 전에 제안해 달라고 함 → 정지 시안 3안(편집 타임라인 바, 방송 고지 한 줄, 컷 전환 와이프)
2. 참고 이미지처럼 편집툴 위에 영상을 얹는 안을 제안. 안전 가이드에 맞추고, 편집툴은 파형 하나 정도, 편집본이 2/3쯤 보이게 → 편집툴 시안 (실제 편집 앱의 버튼, 아이콘, 트랙 색은 따라 하지 않음)
3. 자막을 뺀 아래 검은 빈 곳만큼 편집본을 내려서 다시 보여 달라고 함 → 110px 내린 시안
4. 내린 뒤 전체를 가운데로 맞추라고 함 → 위아래 여백 92px 시안
5. 안전 가이드를 씌우고 편집본은 위, 좌우를 채우라고 함 → 액션·타이틀 안전 영역과 앱 꽉 채우기 추정 범위를 그린 시안
6. 이대로 만들라고 함 → 로컬 편집, 0.5초 간격 프레임 확인, 이슈 초안
7. 빨간 네모만큼 내리고 위를 질감, 빛, 바다로 이어 그려 달라고 함 → Higgsfield Outpaint 4크레딧 안을 알림 → 진행하지 말라고 해서 생성하지 않음
8. 앱 코드에 영상을 붙인 뒤 영상을 바꿀 때 문제없이 교체하는 방법을 물음 → 같은 경로와 이름으로 덮어쓰기, 개발과 미리 정할 것 안내
9. 로컬은 버전 이름 그대로 두고 git에는 이름만 바꿔 올리고, 버전 기록은 콘티와 작업 기록에 남기자고 함 → 그렇게 하기로 함
10. 수정한 V-02를 올리라고 함. 다른 영상 수정은 따로 올리기로 고름 → 이슈 #94, 이 PR
