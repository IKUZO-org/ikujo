## 프롬프트 요약
1. V-06, V-07 글 대체 문구를 먼저 채우고 과거 사고 재현(V-09)으로 넘어가자고 함 → 대체 문구, 이슈 #71
2. V-02, V-03과 V-09의 차이, R3에서 어디까지 보여 줄지 물음 → R3는 절벽을 바라보는 그림자(C안)로 정함. V-09 → V-02, V-03 순서를 기억하라고 함
3. 해와 섬 배경을 빼고 절벽 위 시선으로, 영상 전에 스토리보드 승인을 받으라고 함
4. 절벽을 찍는 설치 카메라 시점, 그림자가 다가오고 손이 로프를 바꾸는 흐름, 위에서 떨어지는 빛, 바닥 그림자만, 이어지는 컷은 같은 그림을 참조하라고 함 (사진 첨부)
5. V-03, V-02 스토리보드를 먼저 확정하고 승인 뒤에 영상을 만들라고 함. 이 브랜치에서 이어서 하라고 함
6. 그날 밤 전체 이야기와 V-02, V-03, V-09의 역할을 다시 정리하고 컷 설명부터 바꾸라고 함 (로고 그림 첨부). 결승 인원과 미션을 물음
7. 고리에서 끊어지는 모습, R2에 CLIFF ROPE 타이틀과 페이드 아웃, 기존 그림 재사용, 필터에 걸릴 말 돌려 쓰기를 요청함 (그림 첨부)
8. 빠드드득과 쿵 소리, V-03 C-02는 손 클로즈업 그림으로 바꾸라고 함 → 만들기
9. 화면이 가운데가 아니고 왼쪽이 늘어졌다고 지적, V-02 앞에 드론 컷을 더하자고 함
10. 출연진이 각자 다른 행동, 최종 내용만 남기기, 레퍼런스 색으로 바꾸기, 암전으로 끝내기, 그림자 형체와 방향, 드론 그림, ffmpeg 색 시험은 한 컷 먼저 보여 주기, CLIFF ROPE 매끈하게를 요청함
11. C-04를 5초로 늘이고 단계별로 풀리며 같은 화각에서 출연진이 달려가며 암전, 형체가 걸어 들어오는 장면 포함, 15초로 나누고 최종 스토리보드를 보여 달라고 함 → 승인, 만들기
12. 로프를 잡기 전부터 사람들이 달려간다고 지적 → 그 구간을 잘라 냄
13. 로프 위에 사람이 둘로 보인다며, 줄이 풀린 상태에서 내려가다 떨어지게 해 달라고 함 → 스토리보드 6칸, 승인, 8초 다시 만들기
14. V-03 손 클로즈업을 ffmpeg로 같은 색으로 바꾸라고 함 → 비교본 두 개 중 "색 + 밝기"를 고름
15. V-02도 바꾸라고 하고, 스토리보드대로 만들라고 함 → 드론 컷 만들어 10초로
16. 드론 컷의 팔을 빠르게 흔드는 사람을 천천한 스트레칭으로, 내려갈 때 구경꾼에게 작은 움직임을 주라고 함. 크레딧을 아끼라고 함 → 그림 고치고 승인 뒤 두 영상 한 번에
17. V-09 9~11초에 절벽과 색이 바뀐다고 지적 → 모양이 다른 참조 그림을 빼고 다시 만듦

19. 레포에 받을 것이 있는지 확인하고 브리핑해 달라고 함 → develop 새 커밋 24개, 겹치는 파일 없음
20. V-07이 나오는 경우(범인 이탈)를 이 브랜치에서 고치라고 함
