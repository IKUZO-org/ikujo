## 할 일
대기실에서 방 코드를 눌러 복사하면 PC는 아래 작은 글자만 바뀌어 알기 어렵다. 토스트로 "복사했어요"를 띄우되, 기기마다 한 번만 보이게 한다.

## 한 일
- 원인 확인: 모바일에서 보인 토스트는 앱이 아니라 안드로이드 13 이상이 복사할 때 띄우는 휴대폰 알림. iOS와 PC는 이 알림이 없어 글자만 바뀌었다
- `src/lib/copy-text.ts`: `systemShowsCopyNotice(userAgent)` 안드로이드면 true. 크롬은 UA 의 안드로이드 버전을 "10"으로 고정해 버전으로는 못 가려서 안드로이드 전체로 본다
- `room-view.tsx` 대기실: 복사에 성공하고 안드로이드가 아니면 방 코드 상자 바로 아래에 토스트 "복사했어요" 3초. 다시 누르면 3초를 새로 센다. 글자("복사했어요", 실패 안내)는 그대로
- `components/game.tsx` `Toast`: `side`("above" 기본, "below")를 받는다. 라운드 토스트(#138)는 그대로 위
- `tests/copy-text.test.ts`: 안드로이드, iPhone, Windows UA 테스트 2개

## 프롬프트 요약
1. git 업데이트 확인과 브리핑 (#139 머지, #142 승인, 다른 팀원 #144 열림)
2. 로컬 화면을 방 만들기(홈)로, 온보딩이 언제 나오는지 확인하고 로컬에 띄우기
3. 추가 수정 두 가지: 방 코드 복사가 PC에서 티가 안 남 → 토스트로 / 앱을 켜면 바로 방 코드라 서비스 느낌을 줄 랜딩
4. 안드로이드는 되고 iOS는 안 되는지, 두 번 안 뜨게 할 방법 질문 → 안드로이드에서만 앱 토스트 빼기(1번)로 결정. 랜딩은 켤 때마다 로고 2초(#146 에서 따로)
5. #139 머지 뒤 develop 에서, 이슈 올리고 진행
