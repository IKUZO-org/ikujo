## A-2. 담당별 전달 사항 (VQ 확정에 따른 할 일)

- [ ] R3 단서 문장(`c-r3-01~04`)을 채워 달라고 요청한다. 영상은 범인 중립 1개이고 범인별 단서는 앱이 글로 얹는다 (VQ-2). 문장이 채워지면 V-02, V-03 초안을 맞춰 고친다

**정연, 현경 (개발)**

- [ ] 공용 영상은 방장 폰만 소리를 내고 다른 폰은 영상을 음소거한다 (VQ-7, sound.md 규칙 1)

## C. 영상마다 하는 검수 (RULES 기준)
영상 하나가 끝날 때마다 이 목록을 그 영상에 대해 한 번씩 돌린다.

**게임 규칙**
- [ ] 범인, 진실 타임라인, 개인 비밀, 범인 특징이 보이거나 들리지 않는다 (R-01)
- [ ] 핵심 4명 중 누가 범인이어도 앞뒤가 맞는다 (R-02)
- [ ] 시각, 장소, 수법이 뼈대와 같다 (R-03)
- [ ] 시나리오에 없는 인물, 사건, 단서, 대사가 없다 (R-04)
- [ ] (R3만) 새 범인이 아니라 이미 준 단서를 다르게 읽게 한다 (R-05)
- [ ] 습격, 피, 상처 클로즈업이 없다 (R-10)
- [ ] 트로피, 원본 하드디스크, 라운드 단서를 영상으로 미리 보여 주지 않는다 (R-11)

**제작 품질**
- [ ] 실제 서비스 UI, 실제 로고, 실존 인물이 없다 (R-06)
- [ ] 소리를 꺼도 이해된다. 자막이나 글 대체 문구가 있다 (R-07, R-09)
- [ ] 영상에 음성(내레이션, 대사)이 들어 있지 않다. 말은 화면 글로만 있다 (VQ-4)
- [ ] 영상 안 소리에 범인 특징(무전기 소리 등)이 없고, 실제 서비스 알림음이나 방송사 징글이 없다 (R-01, R-06)
- [ ] 소리 음량이 다른 영상과 비슷하고, 소리를 꺼도 이해된다 (R-07)
- [ ] 종원의 큐와 겹치는 곳에서 영상 소리가 작게 깔리고, 겹치는 큐와 같은 종류의 큰 소리가 영상에 없다 (R-13)
- [ ] (V-01만) 단톡방 메시지가 PRD §28.2의 한 줄과 같고, 실제 메신저 모양이 아니다 (R-04, R-06)
- [ ] (V-01만) 내레이션 자막이 영상에 구워져 있지 않다. 앱이 영상 아래에 보여 줄 자막 목록(시각, 글)이 콘티에 있다 (VQ-11 결정대로)
- [ ] 판마다 바뀌는 글자가 영상에 구워져 있지 않고, 앱이 얹을 자리가 비어 있다 (R-08)
- [ ] 화면 속에 깨진 글자나 의도하지 않은 글자가 없다
- [ ] 390×844에서 중요한 것이 안전영역 안에 있다
- [ ] 길이, 용량, 화면비가 규격 안이다 (RULES §3)
- [ ] 공통 스타일 블록을 썼고, 팀 아트 디렉션(#23)과 다른 영상과 톤이 같다

**전달**
- [ ] 파일명 규칙, 포스터 이미지, 글 대체 문구가 같이 있다
- [ ] 도구, 모델, 시드, 프롬프트 버전, 쓴 크레딧이 콘티 파일에 기록돼 있다
- [ ] 소리 큐 시각표가 콘티에 있고, 소리 출처, 라이선스, 상업 사용 가능 여부를 기록했다 (R-12)
- [ ] Higgsfield 결과물에 워터마크가 없고(유료), 출처 표시나 메타데이터를 지우지 않았고, 실존 인물의 얼굴이나 목소리를 입력으로 쓰지 않았다 (R-12)

## D. 통합 점검 (P7)
- [ ] 모든 영상의 톤, 로고, 타임코드 스타일이 같다
- [ ] 영상마다 글 대체 문구가 있다
- [ ] iOS Safari와 Android Chrome 최근 2개 버전에서 재생된다 (NFR-005)
- [ ] 소리를 끄고 한 판을 처음부터 끝까지 봐도 이해된다 (NFR-007)
- [ ] 공용 영상은 방장 폰에서만 소리가 나고, 여러 폰에서 틀어도 소리가 겹쳐 울리지 않는다 (sound.md 규칙 1)
- [ ] 영상 소리와 종원의 소리가 겹치는 곳에서 종원의 소리가 먼저 들린다 (큐 목록과 대조, R-13)
- [ ] 영상을 빼도 게임이 돌아간다 (PRD §24)
- [ ] 합계 용량을 개발 담당에게 알렸다
- [ ] 출시 점검(PRD §23)의 4, 5, 6명 판과 범인 4명 플레이 때 영상이 어긋나지 않는지 같이 본다
- [ ] 작업 기록(`docs/work/<아이디>/`)과 PR
