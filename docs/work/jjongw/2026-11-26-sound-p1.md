## 할 일
소리 큐 시트의 P1 큐에 고른 소리를 `public/sounds/`에 넣고 출처와 라이선스를 적는다.

## 한 일
- Freesound CC0 소리 13개를 미리듣기 mp3로 받아 `public/sounds/<ID 소문자>.mp3`로 넣음: LB-02, OP-06, CH-01, RD-03, RD-04, RD-05, R1-01, R2-02, R2-04, R3-02, GH-03, VT-03, RV-03
- 크기 맞춤: 효과음 -16 LUFS 128kbps, 앰비언스와 BGM(OP-06, RD-04, R3-02) -22 LUFS 80kbps, 1분 넘는 루프(R1-01, R2-02, RV-03)는 72kbps로 1MB 이하
- `docs/sound.md` 4번 표에 출처, 라이선스. R1-01은 모닥불만(파도 없음), R2-02는 비와 방 소리만(모니터 웅 소리 없음)

## 프롬프트 요약
1. P1 큐마다 Freesound 후보 4~5개를 찾아 들어 보는 페이지를 만듦
2. 하나씩 들어 보고 고름

## 사용한 skill
- Freesound 검색 MCP(로컬, `~/.config/freesound-mcp`): 후보 찾기와 미리듣기 받기
- ffmpeg: 소리 크기 맞추기
- 이 작업은 ikujo 폴더 밖(다른 레포 세션)에서 해서 아래 사용량이 0으로 나온다

## 확인
- `npm run typecheck` → 통과
- `npm run lint` → 통과
- `npm test` → 122 테스트 통과
- 폰 재생은 안 해 봄 (소리 자리 구현 M3 뒤에)
