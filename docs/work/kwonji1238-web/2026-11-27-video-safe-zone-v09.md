6. 안전 구간에 영상이 크리티컬하게 걸리는지 확인 요청, 오늘은 영상 디테일(안전 구간 벗어난 곳, design과 art.md 어긋남)을 잡겠다고 함, R-14부터 정리
7. V-09에서 구경꾼이 화면 밖으로 많이 벗어나니 절벽 위치만 아래로 내려 안전 구간에 넣고 윗부분은 배경을 이어 달라며 먼저 검토 요청

## 확인

- 소리: `ffmpeg -map 0:a -f md5` 로 새 파일과 교체 전 파일이 같음 (`bd13e7db…`)
