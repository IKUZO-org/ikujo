## 할 일
영상 재생 바탕 `<GameVideo>` 를 만들고 오프닝(V-01), 라운드(V-02, V-03), 유령 연출(V-04, V-05)에 붙인다. 화면 안 소리는 `playSound`(#99) 머지 전이라 자리만 남긴다.

## 한 일
- `src/lib/video.ts`: 영상 주소(`/videos/<ID>.mp4`), 이 폰이 영상 소리를 내는지(`videoHasSound`), 본 기록 키
  - 공용 영상은 방장 폰만(`state.me.isHost`), V-05 는 모든 폰(sound.md 규칙 3, VQ-19), V-04 는 그 영상이 나오는 희생자 폰. 설정에서 소리를 끄면(`isOn("sound")`) 모두 소리 없음
- `src/components/GameVideo.tsx`: 그래픽 영역 안에서 영상을 튼다
  - 처음에는 음소거로 붙이고 소리를 켜서 튼다. 브라우저가 막으면 음소거로 틀고, 화면을 한 번 누르면 소리를 켠다 (sound.md 규칙 6)
  - 영상이 나오는 중에 설정에서 소리를 끄고 켜도 바로 따른다
  - 파일이 없거나 못 틀면 그리지 않는다: 그래픽 영역은 검정, 내용은 아래 글이 맡는다 (PRD §24, DESIGN.md §3)
  - 움직임 줄이기 설정이면 틀지 않는다 (DESIGN.md §7)
  - 한 판에서 끝까지 본 영상은 새로 고침, 탭 바꾸기 뒤에 다시 틀지 않는다 (sessionStorage). 방장 폰 소리가 되풀이되지 않게
  - 끝나면 `onEnded("ended" | "skipped")` 를 불러 영상 뒤 소리(OP-08, OP-04 / 못 틀면 OP-05)를 붙일 자리를 둔다
- `src/lib/settings.ts`: `onSettingsChange` 추가. `setOn` 이 듣는 쪽에 알린다 (영상 음소거를 바로 따르게, #99 의 `playSound` 도 쓸 수 있음)
- `src/components/game.tsx`: `Cover` 가 `graphic` 을 받는다
- 화면에 붙임
  - `opening.tsx`: V-01. 소리 자리 주석(OP-05, OP-06 은 영상 동안 안 냄, 끝나면 OP-08 → OP-04, sound.md 1.1)
  - `round.tsx`: 공용 탭 그래픽 영역에 R2 V-02, R3 V-03. 소리 자리 주석(RD-02, RD-03, GH-03)
  - `ghost-covers.tsx`: 녹화 끊김에 V-04, 출몰에 V-05. 소리 자리 주석(GH-01, GH-04). `GhostCovers` 컴포넌트를 `useGhostCover` 훅으로 바꿔 방 화면이 덮는 화면이 떠 있는지 안다
  - `room-view.tsx`: 오프닝, 라운드에 `isHost` 를 넘기고, 덮는 화면(속보, 녹화 끊김, 출몰)이 떠 있는 동안은 라운드 영상을 틀지 않는다. R2 속보 뒤에서 V-02 가 먼저 지나가 못 보는 것을 막으려고
  - `character-card.tsx`: CH-01 소리 자리 주석 (범인도 같은 소리)
- `tests/video.test.ts`: 소리를 내는 폰 규칙, 소리 끄기, 영상 주소와 본 기록 키, 설정 변경 알림 (5개)

## 프롬프트 요약
1. 소리·영상 분배안 중 2번(영상 바탕 + 화면 안 소리와 영상)을 맡는다. 0번(공통 훅)이 있는지 확인하고 진행
2. 0번은 따로 만들지 않고 방장은 `state.me.isHost`, 소리 설정은 `isOn("sound")` 를 쓰라고 전달받음
3. 이슈(#101)를 만들고 develop 에서 브랜치를 땀. `playSound` 자리는 주석으로만 둔다
4. 코드 작성 진행
5. 로컬에서 직접 보게 띄우고, 볼 것과 빈틈을 꼼꼼히 확인해 달라고 함. 진행하면서 보여 달라고 함
6. 창 4개를 동시에 390×844 로 보는 방법
7. R2 에서 속보만 뜨고 V-02 가 안 나온다는 질문 (속보를 닫아야 나오게 만든 것이라 정상으로 안내)
8. 탭을 바꾸면 끝나기 전의 영상이 처음부터 다시 나오는 것은 그대로 두되, PR 에 적어 팀원 의견을 듣기로 함. 커밋과 PR 전에 내용을 먼저 보기로 함

- `playSound`(#99) 머지 뒤: 주석 자리에 소리 붙이기 (CH-01, RD-02, RD-03, GH-01, GH-03, GH-04, OP-04, OP-05, OP-08). 앱 소리가 나는 동안 영상 소리 줄이기 (video RULES R-13)
- R2-04 (PD 폰 전화): 붙일 화면(S-14 이벤트, FR-044)이 아직 없어 안 붙임
