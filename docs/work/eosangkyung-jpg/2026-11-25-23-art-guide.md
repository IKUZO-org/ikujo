## 할 일
팀이 맞춘 아트 디렉션을 레포 루트의 그래픽 규칙 문서 `ART.md` 로 옮기고, 시나리오와 화면(DESIGN.md)에 맞출 규칙을 더한다.

## 한 일
- `ART.md` 새로 만듦
  - 담당(상경, 영상은 지영과 같이 `제안`)과 근거, DESIGN.md 와의 역할 나눔
  - 아트 디렉션 Mid-Century Graphic Noir, 철학 3개, 그리는 규칙 5개, 질감과 그라데이션(85:15)
  - 색: 팀이 정한 팔레트 A안 6색과 역할별 권장 비중. 쓰지 않기로 한 B안, C안은 넣지 않음
  - 시나리오와 맞출 것: 범인 특징(PRD §28.6) 소품 규칙, 범인 전용 그림 금지, 시나리오 소품만, 고정 뼈대 시각과 맞추기, 실제 서비스·상표 흉내 금지
  - 화면에 넣을 때: 그래픽 영역에만, 그림 안에 설명 글자 없음, 같은 정보는 화면 글로도
  - 첫 시나리오 어셋 목록(우선순위, 쓰는 화면)과 파일 형식 `제안`, 그래픽 PR 체크
- 원본 아트 디렉션의 외부 참고 이미지 링크는 넣지 않음 (임시 주소, 남의 저작물)

### 프롬프트 요약
1. 받을 것이 있으면 다 받아 달라고 함 (두 번)
2. 원격에서 지워진 옛 브랜치를 지워 달라고 함
3. 이제 이미지를 뽑을 차례인지 물음. 이미지는 다른 에이전트로 직접 뽑겠다고 함
4. 영상 담당 지영의 진행 상황을 물음
5. `ART.md` 를 먼저 정하자고 함. 로고는 상경이 미리 만들고, 공통 스타일 블록과 인물 6명을 정하고, 검정 바탕 이음새는 추천대로 하라고 함
6. 작가의 목에 건 줄을 빼는 것과 9:16 화면비의 문제를 물음 → 줄 빼기, 2:3으로 하기로 함
7. 인물 색을 팔레트 안에서 통일하고 실루엣, 옷차림으로만 구별하고 싶다며 시나리오상 문제와 다른 구별 방법, 영상 제작 방식을 물음 → 추천대로 반영하라고 함
8. 작업 기록, 확인, 커밋을 진행하라고 함 → 이어서 push와 PR을 허락함
9. 분위기에 맞는 심플한 캘리그라피 로고 프롬프트를 요청함 → 뽑을 때 팁을 넣은 최종본과 다른 에이전트에 넘기는 법을 물음
10. 지영에게 보낼 메시지를 요청함 → 이모지를 뺀 짧은 버전으로 다시 요청함
11. 앞으로 할 일과, 지영의 답을 기다리는 동안 혼자 할 수 있는 일을 물음
12. 이슈를 만들거나 받을 것이 있는지 확인을 요청함 → PR 리뷰 댓글대로 DESIGN.md 를 고치고 로고 이슈를 만들기로 함
13. 리뷰 댓글에 정해 준 문구로 답글을 달아 달라고 함
14. 지영과 맞출 것을 급한 순으로 물음 → 지금 영상을 최대한 살리는 방법을 물음
15. 지영에게 보낼 정정 메시지를 짧게, 먼저 이야기 가능한지 묻는 말과 나눠서 요청함. 방송 그래픽 표준을 ART.md 에 넣는 것이 맞는지, "공통 모양만 잡는다"의 뜻을 물음
16. 지영과 이야기한 결과를 알려 줌 (영상 3색 유지, 테두리와 REC 점 표준, 타임코드는 지영 것, 로고는 상경, 참고 이미지 허락). 영상 넣는 방식은 오후 PO와 회의에서 정하기로 함 → ART.md 에 반영하라고 함
