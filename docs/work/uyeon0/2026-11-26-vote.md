## 할 일

## 한 일
- `src/server/phase.ts`: vote, revote 도 모두 투표하거나 시간이 끝나면 넘어가게 함. 판정 규칙 `decideTally` (단독 최다 → reveal, vote 동점 → revote, revote 동점/무투표 → 지목 없이 reveal, OQ-008 임시)
- `src/server/game-phase.ts`: `advancePhase` 가 vote/revote 에서 `tally` 로 판정하고, `revote_candidates`, `outcome`(`caught`/`aired_off`)을 단계 전환과 같은 조건부 update 에 씀 → 동시에 불러도 판정 한 번. 투표할 사람 = 살아 있고 나가지 않은 사람. 기록 `vote_done`, `revote`
- `src/server/game-vote.ts`, `src/server/actions/vote.ts`: `vote(gameId, targetPlayerId)`. 한 번만, 바꿀 수 없음, 유령 못 함, 후보 안에서만. 신호는 `{ type: 'count', votes }` 만
- 후보: vote 는 유령이 아닌 참가자 전부(나 포함, 나간 사람도 남김 `제안` #46), revote 는 동점자만
- `getRoomState`: 투표 단계에 `vote`(완료 수, 분모, 내가 할 수 있는지/했는지, 후보, 유령) 추가. 누가 누구를 찍었는지는 없음
- `src/app/(game)/room/[code]/vote.tsx`: S-11 화면 (2열 투표 칸, 고른 칸 테두리와 체크, 유령 칸 흐리게 + "유령", 하단 투표 버튼 n/N, 보낸 뒤 "투표 완료"). 인물 그래픽은 자리만 (#23 전). reveal 은 기존 "다음 화면을 준비하고 있어요" 자리
- `revote_candidates`, `outcome` 은 001 에 있는 칸을 씀
- 나가기 전에 낸 표도 판정에서 뺌 (완료 인원 분모와 같은 기준, BR-011/AC-BR-011 에 맞춘 `제안` #46). `supabase/migrations/006_tally_excludes_left.sql` 로 `tally` 가 나간 사람(`left_at`)의 표를 세지 않게 바꾸고 판정은 `tally` 로 함 (data §3 "집계는 `tally` 만"). 번호 005 는 PR #49 가 씀. 나간 사람의 투표 거절은 기존 참가자 확인(`left_at` 없음)이 맡음
- 점검 반영: 겹치는 판정 단위 테스트 한 줄 지움, 나간 사람이 분모에서 빠지는 것(2/3)을 DB 테스트에 더함, reveal 자리 주석에 이유를 붙임
