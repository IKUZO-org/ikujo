## 할 일
각자 Claude를 쓸 때 토큰, 비용, 5시간/주간 사용률 %가 어디서(브랜치, 이슈, 메인/서브에이전트, 모델) 어떻게(도구, skill, 에이전트) 쓰였는지 PR마다 남기고 팀 합계로 본다.

## 한 일
- `scripts/usage.mjs`: 내 컴퓨터의 Claude Code 기록(`~/.claude/projects/`)에서 이 레포 폴더, 이 브랜치의 메시지만 모아 `## 사용량` 칸을 만든다. 같은 메시지 중복 제거, 세션이 여러 브랜치에 걸치면 비용을 토큰 무게로 나눔. 프롬프트, 경로는 남기지 않는다
- `scripts/claude-statusline.mjs` + `.claude/settings.json` `statusLine`: Claude Code 아래에 "모델 · 5시간 X% · 주간 Y% · 맥락 Z%"를 보이고, 사용률이 바뀔 때만 `~/.claude/ikujo-usage/rate.jsonl`에 남긴다 (PR 칸의 사용률 처음→마지막)
- `scripts/usage-report.mjs`: 작업 기록들의 `## 사용량`을 모아 `docs/usage.md`(사람, 주, 이슈, 모델, 도구별)
- 작업 기록 필수 칸에 `## 사용량` 추가: `check-worklog.sh`, 테스트, `worklog` skill, 양식, `docs/work/README.md`, `CONTRIBUTING.md`, `CLAUDE.md`, `README.md`
- `tests/usage.test.ts` 11개
