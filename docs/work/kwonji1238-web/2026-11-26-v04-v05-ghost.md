## 할 일
V-04(유령 전환)와 V-05(출몰 "생방송 연결")의 콘티, 영상 프롬프트(소리 포함), 스토리보드 이미지를 V-01, V-06, V-07과 같은 3칸 형식으로 만들고, 지영 요청으로 480p 검토 영상도 만든다. V-05 영상 소리를 모든 폰이 같이 내기로 한 지영의 결정을 기록한다.

## 한 일
- `docs/video/storyboards/V-04.md`: 유령 전환 콘티. 희생자 폰에서만 나오고 2초, 컷 2개 (C-01 방송 화면이 가로 띠로 어긋나며 붉은 해가 바래고 REC 점이 꺼짐, C-02 붉은색 없는 옅은 이중 윤곽, 가운데는 앱 자리). AC-050 "2초 안에 뜬다"에 맞춰 4초로 만들어 2배속으로 줄인다. 유령 연출 공통 소리 금지 `{NO-SOUND-G}` 를 여기서 정의했다 (지직거림, 삑 소리, 속삭임, 굉음 금지. 종원의 GH-01~04 몫이거나 범인 특징인 무전기 소리와 닮음, R-01, R-13)
- `docs/video/storyboards/V-05.md`: 출몰 콘티. 모든 폰, 4초, 컷 2개 (C-01 레드 점에서 동심원이 퍼지는 신호 찾기, C-02 테두리와 REC 점만 있는 멈춘 화면, 아래 3분의 1은 유령의 말 자리). 유령의 말과 "생방송 연결" 글자는 앱이 영상 아래에 보여 준다 (R-08)
- 두 콘티 모두 글 대체 문구를 넣었다 (R-09)
- `PLAN.md`: VQ-18 (V-04 길이 2초, AC-050 해석, 확정 전), VQ-19 (V-05 영상 소리는 모든 폰이 같이 냄, 지영 확정). 영상별 소리 표의 V-04, V-05 메모와 "방장 폰만" 원칙에 V-05 예외를 적었다. VQ-3의 검토용 영상 예외를 다섯 개로 넓혔다
- `CHECKLIST.md`: V-04, V-05 진행표(콘티, 프롬프트, 생성 480p 검토본) 체크. A-2에 정연·현경(V-05 음소거 예외, V-04 2초 해석 확인), 종원(V-05 소리가 GH-04와 같이 나감) 전달 사항을 추가했다 (아직 보내지 않아 체크 안 함)
- `RULES.md` §3 위치 행: 검토용 영상 예외에 V-04, V-05를 더해 다섯 개로 넓혔다
- 스토리보드 `V-04_storyboard.jpg`, `V-05_storyboard.jpg` (각 2칸): V-04 Cut 1은 V-07 시작 그림을 다시 썼고, V-04 Cut 2는 GPT Image 2.6로 만들었다. V-05는 두 칸 모두 파이썬으로 직접 그렸다. V-05 Cut 2용으로 만든 이미지는 가운데에 해와 섬을 그려서 쓰지 않았다. 이미지 2장, 2 크레딧
- 영상 (지영 요청, Seedance 2.5, 480p, 4초씩): V-04는 첫 요청이 입력 필터에 걸려(자동 환불) 말을 바꿔 다시 만들었다. V-04 12 크레딧, V-05 12 크레딧 (거래 내역 기준)
- 편집: V-04는 2배속으로 2.0초, 첫 컷에 섞인 지직거리는 잡음을 1.2kHz 저역 통과 필터로 걸러냈다. V-05는 소리 시작에 0.4초 페이드인만 넣었다. 결과 `V-04_ghost_v1.mp4` (0.28MB), `V-05_haunt_v1.mp4` (0.28MB)를 `docs/video/storyboards/` 에 올렸다. 원본과 합친 프롬프트, 입력 이미지는 로컬 `_higgsfield-input/V-04/`, `V-05/` 에만 있다 (git 제외)
- 이슈 #62를 만들었다. Higgsfield 입력 필터와 지직 잡음 거르는 요령을 Claude 기억에 더했다 (레포 밖)

## 프롬프트 요약
1. VQ-16, VQ-17이 무엇인지, 다음에 할 일이 무엇인지 물음 → 설명과 우선순위 안내 (이전 PR #56 머지 뒤)
2. V-04, V-05 이슈 초안을 보여 달라고 함 → 초안 제시
3. V-05 영상 소리도 GH-04처럼 모든 폰이 같이 내라고 정함 → 초안에 반영
4. 이슈를 만들어 달라고 함 → #62 생성
5. 시작하라고 함 → 브랜치, V-04, V-05 콘티, PLAN VQ-18·19, CHECKLIST
6. 스토리보드 이미지를 만들라고 함 → 이미지 2장 생성(2 크레딧), 시트 2장
7. 커밋부터 하라고 했다가, 영상을 먼저 만들어 달라고 함 → 영상 2개 생성, V-04 편집과 잡음 거르기, V-05 페이드인, 콘티와 규칙 문서에 기록
8. 이어서 커밋 → 이 기록을 쓰고 커밋
