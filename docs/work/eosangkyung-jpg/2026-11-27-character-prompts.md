## 할 일
인물 6명(fav, villain, athlete, writer, influencer, medic) 이미지를 만들 프롬프트를 레포 문서로 정리하고, 1차 이미지를 뽑아 시나리오 담당(정연)에게 확인받을 준비를 한다.

## 한 일
- `docs/art/characters.md` 새로 만듦
  - 1번: 6명 각각 바로 복사해 쓰는 완성 프롬프트(스타일 + 구도 + 인물)와 공통 금지 목록
  - 스타일은 ART.md §8에서 가져와 인물용으로 바꿈: 팔레트 6색을 모두 쓰되 역할 고정(바탕 Ink Black, 빛 Ivory, 그림자 Petrol Teal, 강조 Vermilion 옷 한 군데 5% 이하, Burgundy 가장 깊은 그림자, Amber 빛 닿는 가장자리), 빛 하나(왼쪽 위), 배경 무늬는 Teal과 Ivory 평평한 면만, 비대칭 구도 문장은 뺌(6명이 같은 자리)
  - 성별과 나이는 모호하게 (`gender-neutral and age-ambiguous silhouette`)
  - 2번 인물 표(ART.md §9와 같음), 3번 넣지 않는 것과 이유(범인 특징 `t-*`, 단서 `c-*`, 수상해 보이는 자세), 4번 뽑을 때(같은 도구·참고 이미지·시드, 결과는 `docs/art/characters/<ID>-v<버전>.png`), 5번 뽑은 뒤 확인, 6번 생성 기록, 7번 바꾼 기록, 8번 정할 것(CQ-1 PO 범위, CQ-2 정연 확인, CQ-3 앱 이미지 위치)
- 이 브랜치는 ART.md(#81)가 머지되기 전에 develop 에서 땄다. 문서 안의 ART.md 링크는 #81 머지 뒤에 열린다
- 프롬프트를 다시 씀 (커밋 2)
  - 6명이 같은 곳을 보는 것 같아 몸 방향을 인물마다 다르게 함 (왼쪽 3/4 둘, 오른쪽 3/4 하나, 옆모습 둘, 정면 하나). 등 돌림, 고개 숙임, 돌아보기는 금지 목록에 넣음
  - 6명이 비슷해 보일 수 있어 체형, 머리, 옷 구조, 손동작을 인물마다 확실히 다르게 함 (예: 단발·꽈배기 니트, 넘긴 머리·긴 코트, 민 머리·트레이닝 상의, 똥머리·후드티, 긴 생머리·트렌치코트, 가르마·튜닉)
  - 인물 설명을 프롬프트 맨 앞으로, 공통 스타일과 틀은 줄여서 뒤로. 각 블록에 `Avoid:` 줄까지 넣어 그대로 복사해 쓰게 함
  - 금지의 `props in hands` 를 `objects held in hands` 로 (손동작은 되고 물건은 안 됨)
- 그 뒤 develop(#81 머지 포함) 위로 이 브랜치를 옮김

## 프롬프트 요약
1. 인물 6명 프롬프트부터 하자고 함 → 채팅으로 프롬프트를 받음
2. 프롬프트를 md 파일로 만드는 게 과한지 물음 → 처음에는 바탕화면에 저장
3. docs에 남기는 경우가 무엇인지 물음 (지영의 `docs/video/` 방식) → 이슈를 만들어 docs로 하기로 함
4. 제안이 PRD와 규칙에 맞는지 물음 → FR-081에 인물 일러스트가 직접 없다는 점을 확인하고 이슈 본문에 PO 확인 필요로 적기로 함
5. ART.md(#81) 상태와 develop 받을 것을 확인하라고 함 → develop 받음, PO에게 #81 머지·문서 표·인물 범위를 묻는 메시지를 짧게 정리
6. 인물 이슈(#87)를 만들라고 함
7. 이슈가 있는데 왜 바탕화면에 저장하냐고 함 → 이 브랜치를 따서 `docs/art/characters.md` 로 옮기고 바탕화면 폴더를 지움
8. 1차 이미지를 뽑은 뒤 정연에게 확인받겠다고 함
9. 프롬프트 문서가 잘 정리됐는지 물음 → 바로 복사해 쓰는 구조로 다시 씀. 성별과 나이는 모호하게
10. 통일성과 팔레트 포함 여부를 다시 검토하라고 함 → 6색 중 버건디와 앰버가 빠진 것을 찾음. A안(6색, 역할 고정)으로 고치라고 함
11. 커밋하자고 함
12. 인물별 프롬프트를 정리해 달라고 함 → 공통 금지까지 각각 넣어 달라고 다시 요청함
13. 6명이 다 같은 곳을 보는 것 같다며 구도를 자연스럽게 다르게 해 달라고 함
14. 벡터 목업으로 테스트 이미지를 뽑아 달라고 했다가 멈추고, 포즈·생김새·옷 구조가 확실히 구분돼야 하지 않냐고 물음 → 제안한 표대로 프롬프트를 다시 쓰라고 함
15. 받을 것 확인 → #81 머지를 확인하고 develop 받기, 이 브랜치 옮기기, 옛 브랜치 지우기를 하라고 함
