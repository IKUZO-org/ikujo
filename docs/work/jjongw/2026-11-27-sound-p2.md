## 할 일
`docs/sound.md` 큐 시트의 P2 6개(LB-01, OP-01, CL-01, GH-02, VT-02, RV-04)를 찾아 `public/sounds/` 에 넣는다.

## 한 일
- Freesound CC0에서 자리마다 3개씩 후보를 찾고, 들어 보고 고르는 페이지를 만들어 PO가 고름
- VT-02는 처음 후보(Message Bubble)가 너무 밝아서 낮은 소리 후보 5개를 다시 찾아 UI Button Press Deep으로 정함. 실제 서비스 문자 소리를 닮은 후보는 뺌 (BR-008)
- 크기 맞춤: 효과음(LB-01, CL-01, VT-02, RV-04) -16 LUFS 128kbps, 루프(OP-01, GH-02) -22 LUFS 80kbps. 모두 1MB 이하 (가장 큰 gh-02 459KB)
- `docs/sound.md` 4번 표에 6줄, 상태 줄과 4번 끝 문장을 P2까지로 고침

## 프롬프트 요약
1. "P2 소리 찾아보자" → 후보 표와 들어 보는 페이지 (누르면 고른 번호가 복사되게)
2. PO가 고름, VT-02만 다시 → 낮은 소리로 다시 고름 → 받고 크기 맞춰 PR

## 사용한 skill
- 없음. Freesound API(키는 로컬 파일)와 ffmpeg loudnorm
- 이 작업은 ikujo 폴더 밖(다른 레포 세션)에서 해서 아래 사용량이 0으로 나올 수 있다

## 확인
- `npm run typecheck` → 통과
- `npm run lint` → 통과
- `npm test` → 133 테스트 통과
- VT-02, RV-04는 0.4초보다 짧아 LUFS 측정이 안 돼서 최고 -2 dB, 평균 -18 dB 로 다른 효과음과 비슷한지 확인
