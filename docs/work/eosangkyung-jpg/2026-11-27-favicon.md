## 할 일
PO가 부탁한 파비콘을 만든다. Next.js 기본 아이콘을 바꾸고 홈 화면용 아이콘을 넣는다.

## 한 일
- `src/app/icon.svg`: 512 기준. 바탕 `#0B0B0B`, 아이보리(`#F2EBDC`) 꺾쇠 4개(가장자리에서 64, 팔 150, 두께 40), 가운데 Vermilion(`#BF3026`) 점(반지름 72). 글자 없음
- `src/app/apple-icon.png`: 같은 SVG를 180×180 PNG로
- `src/app/favicon.ico`: Next.js 기본 아이콘을 바꿈. 같은 SVG의 16, 32, 48px PNG 세 장을 담은 ICO
- 변환은 레포에 이미 있는 `sharp`(Next.js 의존성)로 함. 새 패키지 없음

## 프롬프트 요약
1. PO가 로고 작업하면서 파비콘도 만들 수 있는지 물었다며 이슈로 올릴지 물음 → #83과 따로 이슈로 추천
2. 로고는 A로 정했다고 알려 줌 → A 글자로 파비콘 시안 3개(L, L+레드 점, LO)
3. LAST / ONE 두 줄을 제안 → 시안 2개(여백 넉넉, 글자 크게), 두 시안을 크게 나란히 보여 달라고 함
4. 두 줄 여백 넉넉한 것을 시안 1로 두고, 포커스 프레임과 빨간 점만 있는 시안을 하나 더 만들어 달라고 함
5. 시안 2(꺾쇠 + 빨간 점)로 정함 → 이슈를 만들고 진행해도 좋다고 함

## 확인
- 개발 서버(`next dev`)에서 `/favicon.ico`, `/icon.svg`, `/apple-icon.png` → 모두 200, 형식 `image/x-icon`, `image/svg+xml`, `image/png`, 받은 파일이 `src/app/` 파일과 같음
- 첫 화면 `<head>` 의 아이콘 링크 → 확인 못 함. 이 폴더에 `.env.local` 이 없어 페이지가 Supabase 환경 변수 오류(500)로 열리지 않음 (아이콘과 관계없음). PR의 Vercel 미리보기에서 본다
- `file src/app/favicon.ico` → 아이콘 3개(16, 32 PNG ...), `apple-icon.png` 180×180
- `npm run typecheck` → 통과
- `npm run lint` → 통과
- `npm test` → 통과 (13개 파일, 144개 테스트)
- 실제 폰 홈 화면 추가 → 안 해 봄
